# ExecuteOS — Product Specification (Condensed)

> Full detailed specification lives in conversation history. This is the living summary.

## Vision
Help individuals and small teams consistently convert commitments into completed work.

**Philosophy:** Don't just manage your tasks. Make sure they actually get done.

## Core Loop
Plan → Organize → Remind → Execute → Track → Analyze → Improve

## Unique Differentiator
**Execution Intelligence** — the system continuously answers:
- What is the highest-leverage thing I can do right now?
- Am I overcommitted?
- Which commitments are at highest risk?
- What follow-up did I just create?

## Target ICP (Wedge)
Freelance consultants, independent professionals, solopreneur agency owners.

## MVP Scope
- Auth + onboarding
- Smart Today dashboard
- Tasks + multi-stage reminders + intelligent scheduling suggestions
- Basic meetings + post-meeting follow-up prompt
- Simple goals
- Daily plan generation
- AI Coach (core commands)
- Transparent Discipline Score
- Google Calendar sync
- Push + email reminders

## Out of MVP
Full team workspaces, heavy PM views, Slack replacement, complex integrations, advanced AI agents.

## Success Metric (North Star)
**Completed planned actions per active user per week**

## Principles
1. Every feature must increase the probability that important work gets done on time.
2. Less planning theater. More execution.
3. AI proposes. User confirms sensitive actions.
4. Transparent scores only.
